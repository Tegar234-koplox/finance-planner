# Finance Planner — Phase 1 preview

Download `FinancePlanner-Phase1-preview.apk` and install on Android 8.0 or newer.

This is a debug navigation/storage foundation. It includes Home, Budget, Plan,
Market empty states, Settings appearance, Room, and DataStore. Transactions,
budget calculations, goals, and market feeds are not implemented yet.

Build, 34 JVM tests, lint (0 errors), and debug signature verification passed.
Device/instrumentation checks are pending; this is not a production release.
